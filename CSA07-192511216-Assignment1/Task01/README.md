## 1. Objective
Calculate the network traffic generated by one production line and an eight-line plant.

## 2. Traffic Calculations

| Source | Traffic per line |
|---|---:|
| Robot controllers | 32 Mbps |
| Vibration sensors | 0.24 Mbps |
| CCTV cameras | 96 Mbps |
| Office users | 30 Mbps |
| **Total** | **158.24 Mbps** |

**Traffic for 8 lines:**

8 × 158.24 = **1,265.92 Mbps ≈ 1.27 Gbps**

## 3. Analysis
- CCTV generates the highest traffic.
- Robot controllers have the strictest delay requirement (10 ms).
- A single 1 Gbps uplink is insufficient for eight production lines.
- Robot traffic should receive priority over CCTV traffic using QoS.

## 4. Traffic Ranking for a 100 ms Delay
1. Robot control – exceeds the 10 ms deadline.
2. Vibration sensors – delayed readings may affect emergency alerts.
3. CCTV – buffering can absorb some delay.
4. Office traffic – generally tolerates short delays.

## 5. Alternative Concept
If CCTV sends motion-triggered clips only 5% of the time:

- CCTV traffic = 4.8 Mbps per line.
- Revised line traffic = 67.04 Mbps.
- Revised plant traffic = 536.32 Mbps.

The 1 Gbps uplink is sufficient under this alternative traffic assumption.

## 6. Conclusion
The network should use a higher-capacity uplink for continuous CCTV streaming, separate traffic queues, and priority handling for robot commands.
