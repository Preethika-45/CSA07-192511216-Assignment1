# Task 09 – How Big Must the Window Be?

This folder includes a bandwidth-delay-product calculator. The assignment's worked WAN example uses a 1 Gbps link and a 12.6 ms RTT; with 1,500-byte frames, the bandwidth-delay product is about 1.575 MB, or 1,050 frames (confirm the exact frame/window assumptions in the task text and your report). A stop-and-wait protocol is inefficient on a long-delay, high-bandwidth path.

Run `python task09.py`. Check the printed values against the exact window/sequence-number assumptions stated in the assignment before submitting.
